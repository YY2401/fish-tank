# 🐠 Fish Tank — 直播互動水族箱（純靜態，免安裝）

觀眾在 Twitch 聊天室講話或打指令，就會變成一隻魚在直播畫面裡游泳：換魚種、換顏色、跳、衝、轉圈、睡覺、餵食長大、抱抱別人。
純前端網頁，OBS 加一個瀏覽器來源就能用；讀聊天室用匿名連線，**不用登入、不用 Client ID**。

**👉 線上使用：<https://yy2401.github.io/fish-tank/>**（打開設定頁 → 填頻道 → 複製 OBS 網址）

**📘 教學圖文**：[快速上手](docs/直播水族箱_快速上手_20261031.png)・[觀眾指令（可以放在直播畫面或頻道介紹）](docs/直播水族箱_觀眾指令_20261031.png)・[完整使用說明書 PDF](docs/直播水族箱_使用說明書_20261031.pdf)

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 設定頁：填頻道、調選項、偵測忠誠點品項、接 Google 試算表，產生 OBS 網址，附可模擬指令的預覽 |
| `tank.html` / `tank.js` / `tank.css` | OBS 用的水族箱畫面（Canvas） |
| `fish-core.js` | 純邏輯：指令解析、魚種與顏色、冷卻、IRC 解析、網址參數。瀏覽器與 Node 共用 |
| `chat.js` | 匿名讀 Twitch 聊天室（IRC over WebSocket） |
| `sheet-script.gs` | 貼到 Google 試算表的 Apps Script，存每隻魚的外觀（換電腦也記得） |

## 觀眾指令

| 指令 | 效果 |
| --- | --- |
| `!魚`（或直接講話） | 變成一隻魚加入，講的話變成對話泡泡 |
| `!鯊魚` `!河豚` `!水母` `!金魚` `!小丑魚` `!神仙魚` | 換魚種（也可以 `!變 鯊魚`） |
| `!鯨魚` `!獨角鯨` `!錦鯉` | 稀有魚種，解鎖過才能換 |
| `!顏色 粉`／`!顏色 彩虹`／`!顏色 #66ccff` | 換顏色 |
| `!跳` `!衝` `!轉` `!睡` `!泡泡` | 動作（河豚膨脹、鯨魚噴水） |
| `!餵`／`!餵 @名字`／`!餵 大家` | 撒飼料給自己／請別人吃／全場一起吃，吃到會變大（最大 2 倍） |
| `!頭像 <表情符號>`／`!頭像 大頭貼`／`!頭像 關` | 把表情符號或 Twitch 大頭貼貼在魚身上／拿掉 |
| `!<自訂魚種名稱>` | 實況主在設定頁加的限定魚種（上傳圖片或圖片網址） |
| `!抱 @名字`／`!跟 @名字` | 抱抱冒愛心／跟著游 30 秒 |
| `!離開`、`!fishhelp` | 游走、畫面顯示說明 |
| `!tank shark｜whirl｜treasure｜feed｜clear` | 實況主／管理員：鯊魚出沒、大漩渦、寶箱、全場餵食、清空 |

## 稀有魚種怎麼解鎖

訂閱／續訂／被送訂閱、一次贊助 N 小奇點（預設 100，訊息寫魚種名就解鎖那隻）、兌換忠誠點品項、搶到寶箱；揪團進來的實況主直接送鯨魚。

忠誠點限制：不登入只讀得到「**需要觀眾輸入文字**」的品項。設定頁填好頻道後兌換一次，品項就會出現，選它要做什麼。

## 大事件

每 N 分鐘隨機一次（預設 15，0 關閉）：🦈 鯊魚出沒（魚四散逃跑、有魚被咬飛）、🌀 大漩渦、💰 寶箱掉落（第一隻碰到的解鎖稀有魚種）；有人揪團時會有 🐟 魚群游過。

## OBS 網址參數

| 參數 | 說明 | 預設 |
| --- | --- | --- |
| `channel` | Twitch 頻道（必填） | |
| `auto=0` | 要打 `!魚` 才加入（預設講話就加入） | 1 |
| `say=0` | 不顯示聊天泡泡 | 1 |
| `bg=none` | 透明背景，只畫魚 | tank |
| `top` `bottom` `left` `right` | 水族箱範圍：上下左右各留白畫面的幾成（0～0.85）。不是全畫面時，完整背景模式畫成玻璃魚缸、其他地方透明 | 0 |
| `scale` | 魚的大小倍率 | 1 |
| `max` / `idle` | 最多幾隻魚／幾分鐘沒講話就游走 | 60 / 20 |
| `tip=0` | 不顯示底部指令提示 | 1 |
| `deco` | 裝飾：`castle,chest,coral,bubbler` | chest,coral,bubbler |
| `event` | 大事件間隔分鐘（0 關） | 15 |
| `bits` / `subs=0` | 解鎖稀有魚種的小奇點門檻（0 關）／訂閱不解鎖 | 100 / 1 |
| `rw` | 忠誠點品項：`品項ID:動作,…`（rare、shark、whirl、treasure、feed） | |
| `store` / `skey` | Google 試算表網頁應用程式網址與暗號 | |
| `skin` | 自訂魚種：`名字\|https://圖片網址`，可以有好幾個 | |
| `pfp=0` | 不讓觀眾用 `!頭像 大頭貼`（大頭貼透過 decapi.me 查詢） | 1 |
| `demo=1` | 顯示測試面板（模擬聊天、訂閱、小奇點、揪團、大事件） | |
| `ignore` | 不變成魚的帳號（逗號分隔） | 常見機器人 |

## 開發

```bash
npm start          # http://localhost:3010
npm test           # 單元測試：核心邏輯 + Apps Script（假試算表）
npm run test:e2e   # 瀏覽器測試：真的 Chrome 開水族箱與設定頁（Twitch、試算表用模擬）
node docs/shots.js # 重新產生教學用截圖（docs/img）
node docs/video/demo.js  # 重新錄功能展示影片（需要 ffmpeg）
```
