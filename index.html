🐠 直播水族箱 觀眾在聊天室打指令，就會變成魚在你的直播畫面裡游泳

1. 基本設定

水族箱範圍
魚只會在這個範圍裡游。不是全畫面時，完整背景模式會畫成一個玻璃魚缸，其他地方透明，可以疊在遊戲畫面上。

2. 魚缸外觀與大事件

配色（背景選「完整水族箱」時才有）
畫面上要有哪些東西
魚缸物件
城堡、沉船、珊瑚、海星…在右邊預覽下面的「魚缸物件」加，直接在預覽上拖曳位置、調大小與顏色。

3. 自訂魚種與觀眾外觀

本頻道限定魚種
取個名字、按「上傳」選一張圖，觀眾打 !名字 就會變成這張圖游來游去。建議用透明背景、魚頭朝右的 PNG。
上傳的圖會自動縮小、直接放進 OBS 網址，不用任何帳號。網址有長度上限，大約可以放 3～4 張。
觀眾頭像
觀眾打 !頭像 加一個表情符號，那個表情就會貼在他的魚身上（表情都經過 Twitch 審核）。打 !頭像 關 拿掉。
觀眾自己打扮
觀眾可以隨時用 !戴 帽子／皇冠／眼鏡／蝴蝶結／海盜帽／花／耳機／光環 和 !花紋 條紋／斑點／星星／愛心，跟魚種、顏色、頭像自由搭配，不用設定。

4. 稀有魚種（鯨魚、獨角鯨、錦鯉）

一般觀眾打 !鯨魚 會被擋下來，要用下面的方式解鎖。解鎖會直接變身並出現全場橫幅。被揪團進來的實況主直接送一隻鯨魚。
忠誠點品項
不用登入的限制：品項要勾「需要觀眾輸入文字」，水族箱才看得到兌換。
設好頻道後，自己或請觀眾兌換一次，品項就會出現在下面，選它要做什麼。
填頻道名稱後開始偵測
進階（選用）：換電腦也記得每隻魚 大部分人不需要這個：觀眾的魚（魚種、顏色、配件、長大的大小）平常就記在 OBS 裡，同一台電腦開台都還在。只有要換電腦或重灌 OBS 時才需要接 Google 試算表；設定要進 Google Apps Script，比較麻煩。
  1. 開一份新的 Google 試算表 → 擴充功能 → Apps Script
  2. 整段貼上（取代原本內容）→ 儲存
  3. 部署 → 新增部署作業 → 類型「網頁應用程式」，執行身分「我」、存取權「所有人」→ 部署（第一次會要求授權）
  4. 把網頁應用程式網址貼到這裡：
程式碼裡有一組只屬於你的暗號，OBS 網址也會帶著它。換一組暗號（換了要重新複製程式碼、重新部署）

5. 複製到 OBS

OBS → 來源 → ＋ → 瀏覽器 → 貼上網址，寬 1920、高 1080。透明模式不用另外設定背景。改了上面任何設定都要重新複製。
